QS 2.1: The minimax algorithm was solved using a recursive method.
        The function recursively searches through every legal actions recursively.
        If the given state's depth is equal to the search depth or it is a leaf node,
        then it returns the evaluation of the current state. As the function returns the 
        reward value, it backtracks to where the function call was made, where the reward
        value is then compared to only save the optimal value and corresponding action. 
        This recursive nature backtracks all the way to the root node where it will find its
        appropriate optimal action. 

QS 3.1: The AlphaBetaAgent and the MinimaxAgent behaves identically as AlphaBeta Pruning 
        algorithm is an extension of Minimax where it avoids visiting nodes that are guaranteed
        to not change the outcome. Therefore, the behaviour of the two agents are identical however,
        the AlphaBetaAgent is able to achieve the same outcome with fewer computations.

QS 3.2: As instructed for grading purposes, the nodes are not pruned when they have give the same 
        reward value. The node that came first is given priority, thus if action East and West gives
        the same reward and action East was observed first, then the AlphaBetaAgent will stick with 
        the action East as it was the first visited node.
